# v0.1.0-alpha.4 — native lttl compression

This build integrates lttl Fast and optimized lttl Dense into the Windows app and CLI. Native `.lttl` is the default for new archives; Auto compares numeric choices with ordinary Zstandard per block, with separate speed and size goals. Manual codec choices and actual block counts are exposed in the Windows Create screen.

The new bounded `LTTLAR01` container supports multiple files, empty directories, large-file block processing, content checksums, safe extraction and the existing identity-encrypted envelope. ZIP, TAR.ZST, TAR.LZ4 and older encrypted payloads remain readable. Older clients cannot read new native payloads. A `.lttl` suffix alone does not mean encrypted; enable organization sharing explicitly.

This installer also includes the current Audit & retention desktop screen. Native codecs run on CPU; existing portable and NVIDIA GPU paths remain available for their respective TAR formats.

See [usage and format](../native-compression.md), [production measurements](../native-codec-benchmark.md) and [installer instructions](../windows-installer.md). This is a locally built unsigned alpha installer; building it does not publish a GitHub release.
