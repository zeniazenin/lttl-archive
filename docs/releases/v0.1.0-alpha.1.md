# lttl 0.1.0 alpha 1

First Windows x64 installer release of lttl, a Rust archiver with a desktop UI, CLI, CPU/GPU compression and identity-protected sharing.

## Download and install

Download **lttl-0.1.0-alpha.1-windows-x64-setup.exe** from this release's assets. Compare `Get-FileHash -Algorithm SHA256` with the companion `.sha256` file before running it. Windows 10/11 x64 is required.

Installation is per user and includes the GUI/CLI, CPU codecs, portable wgpu LZ4 and app-local MSVC runtimes. NVIDIA Zstandard acceleration and Explorer menu actions are optional. It creates Start Menu shortcuts and an uninstaller. Existing lttl installations must be uninstalled first; archives, identity profiles and user-added files are preserved.

**This is an unsigned alpha build.** Windows may show an unknown-publisher or SmartScreen warning. No GPU driver, cloud broker, database or IDP configuration is installed automatically.

## Included functionality

- Create, list, test and extract ZIP, TAR.ZST and TAR.LZ4.
- Content-aware Zstandard Auto selection; Fast avoids sampling overhead.
- NVIDIA nvCOMP Zstandard and portable wgpu LZ4 experiments.
- Optional Explorer create/extract actions.
- Encrypted `.lttl` sharing through fresh IDP authentication and a key broker, with Azure Key Vault, AWS KMS and Google Cloud KMS wrapping.
- Serverless deployment templates, Entra/other-provider setup instructions, benchmark reports and development documentation.

## Validation and limits

The desktop suite passed **32 tests**, with seven hardware-dependent tests skipped. The installer passed **14 checks**, covering both component selections, payload hashes, ZIP/TAR.ZST/TAR.LZ4 round trips, existing-install refusal and uninstall preserving a user-added file. Its optional NVIDIA runtime detected the RTX 4070 Laptop GPU. Visual wizard appearance and the optional Explorer installation step remain outside this smoke test.

Recorded GPU benchmarks include transfer/readback time and compression ratios. RTX portable LZ4 won warm speed on 7/9 datasets but produced larger archives; Intel had no CPU speed wins. Auto TAR.LZ4 therefore remains on CPU. AMD and Apple hardware are untested.

Identity/KMS tests use local contracts and mock OIDC; live cloud deployment and tenant policy enforcement still need pilot validation. Serverless packages have not been built or deployed here. RAR/7z, split volumes, recovery records and complete Windows metadata preservation are not implemented.
