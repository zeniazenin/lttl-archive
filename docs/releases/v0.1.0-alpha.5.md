# v0.1.0-alpha.5 - Program Files and installer repair

Setup now defaults to `C:\Program Files\lttl`, requests administrator elevation, and registers the app and shortcuts for all users. The directory validator no longer disables Install when `lttl.exe` exists. Registered machine installations can be repaired/upgraded in place; unregistered files and locked executables receive explicit explanations before replacement.

Optional Explorer commands use the all-users registry scope in setup. Existing component choices are preselected during repair. Standalone scripts retain their current-user default with an explicit `-Scope AllUsers` option.

Uninstall older per-user AppData versions before migrating. Archives and identity profiles are retained. Native codecs and archive formats from alpha.4 are unchanged. [Installation instructions](../windows-installer.md).
