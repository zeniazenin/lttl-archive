# v0.1.0-alpha.6 - Desktop startup and app icon

Start Menu and Explorer actions now use `lttl-gui.exe`, a Windows GUI executable
that opens the app without allocating a console window. `lttl.exe` retains
normal terminal output and exit codes for command-line use. Its legacy GUI
commands detach their console before opening the interface.

The original logo from [lttl.info](https://lttl.info/assets/logo.png) is embedded
in both executables, the app window, installer and uninstaller. The Start Menu
shortcut and Installed Apps entry also use it. Existing owned Explorer commands
are refreshed during upgrade to use the desktop launcher.

Close lttl before running setup. Install over the registered alpha.5 installation
to retain its location and optional component choices. Archive codecs and formats
are unchanged from the local alpha.4/alpha.5 builds. [Installation instructions](../windows-installer.md).


Compared with the previously published alpha.3, this release also includes native
lttl Fast/Dense compression, per-block Auto selection, the Windows Audit & retention
screen and broker activity endpoint, and Program Files installation with repair.
Older native-payload recipients need alpha.4 or newer. Deploy the matching broker
source from this tag for administrator activity; desktop setup does not deploy it.

The production comparison completed 90 exact-recovery archive/extraction pairs.
On original EEG, lttl Dense was 4.4x faster and 13.6% smaller than RAR method 5;
RAR remained denser on the text control. CPU results are workload- and setting-specific.
See the [complete comparison](https://github.com/zeniazenin/lttl-archive/blob/v0.1.0-alpha.6/docs/archive-comparison.md).

Validation: 53 desktop/library/integration test executions (seven hardware tests
skipped, four GUI tests repeated across the two executable targets), 17 broker tests
(one PostgreSQL test skipped), and 171 installed-client checks with 62 fresh mock-IDP
flows. Live cloud/IDP acceptance remains pending. The Windows installer is unsigned.
