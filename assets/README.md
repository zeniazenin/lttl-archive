# lttl artwork

Original logo: https://lttl.info/assets/logo.png (retrieved October 13, 2026).
Used at the project owner's request. `lttl-logo.png` is the original download.
`lttl-icon.png` and the multi-resolution `lttl.ico` preserve the complete artwork
and aspect ratio, centered on a white square for Windows app icons.

The executable resources, desktop window, installer, uninstaller, Start Menu
shortcut and Installed Apps entry use this artwork.
